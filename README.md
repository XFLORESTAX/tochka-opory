# ТОЧКА ОПОРЫ

Русскоязычный сайт консультаций и клуба «Ближе к себе». Независимый проект на Next.js, React, TypeScript и Tailwind CSS.

## Запуск

Требуется Node.js 22 или новее.

```bash
npm ci
cp .env.example .env.local
npm run dev
```

Откройте http://localhost:3000. Режим черновика по умолчанию отключает отправку заявок и индексацию. Каталог услуг, тарифы и темы клуба находятся в `lib/catalog.ts`.

## Проверка и production

```bash
npm run typecheck
npm run build
npm start
```

Разверните проект как отдельное Node.js-приложение с собственным доменом и HTTPS. На платформе используйте команды `npm ci`, `npm run build` и `npm start`. Для standalone-развёртывания скопируйте `public` в `.next/standalone/public`, а `.next/static` в `.next/standalone/.next/static`, затем запустите `node .next/standalone/server.js`. Артефакт собирается с нужными значениями `SITE_DRAFT` и `SITE_URL`. Эти же значения передаются серверу при запуске. Секреты передаются только серверному процессу через хранилище секретов хостинга.

Перед открытием записи заполните разделы о специалисте и подтверждённом образовании, добавьте реквизиты и утверждённые тексты `/privacy` и `/terms`. Отзывы добавляются с разрешения авторов. До готовности этих материалов держите `SITE_DRAFT=true`. Для приватного предпросмотра используйте контроль доступа хостинга. Запрет индексации сам по себе доступ не ограничивает.

## Серверная доставка заявок

- `SITE_URL` — канонический адрес сайта. Сервер принимает запросы с этого origin.
- `SITE_DRAFT=false` — включает приём заявок после утверждения материалов и настройки доставки.
- `BOOKING_CLIENT_IP_HEADER` — имя заголовка с одним IPv4 или IPv6. Внешний доверенный прокси обязан перезаписывать этот заголовок. Закройте прямой доступ к Node.js в обход прокси.
- `BOOKING_SECRET` — случайный серверный секрет длиной от 32 символов. Например, сгенерируйте его через `openssl rand -hex 32`.
- `REDIS_REST_URL` и `REDIS_REST_TOKEN` — HTTPS REST API Redis, совместимый с Upstash и командой EVAL. До пяти запросов на IP за 15 минут, с атомарным счётчиком и сроком хранения. При сбое Redis приём заявок приостанавливается.
- `BOOKING_WEBHOOK_URL` и `BOOKING_WEBHOOK_TOKEN` — HTTPS-адрес и Bearer-токен вашего приёмника заявок. Выберите обработчик и регион хранения с учётом утверждённой политики.

Приёмник получает JSON с полями `id`, `name`, `contact`, `service`, `time` (локальная дата и время), `zone`, `consentedAt`. Храните данные только в утверждённом месте. Возвращайте HTTP 2xx и JSON `{"delivered":true,"id":"<id из запроса>"}` после подтверждённой передачи или записи в рабочую очередь обработки. Приёмник может использовать заголовок `Idempotency-Key` для повторной обработки одного идентификатора. Контакт в виде Telegram принимается как имя пользователя. Автоматическая передача заявок в Telegram отсутствует.

Страница `/success` открывается при наличии подписанного сервером подтверждения, действующего 15 минут. При недоступности или неоднозначном ответе приёмника форма показывает ошибку доставки.

## Оплата

`lib/payments.ts` содержит отключённую точку расширения. После выбора провайдера потребуются адаптер с проверкой подписи по исходному телу запроса, серверная сверка платежа и атомарная запись с уникальностью события и платежа. Сайт не запрашивает банковские данные.

## Изображения

Локальные фотографии из Unsplash размещены в `public/images` и используются через оптимизатор Next.js. Шрифты Manrope и Cormorant Garamond поставляются локально через Fontsource.

## Статический черновик

`npm run preview:build` собирает отдельный статический черновик в `dist/` с отключённой отправкой. Для рабочего сайта с обработчиком заявок используйте Node.js-развёртывание из раздела «Проверка и production».
